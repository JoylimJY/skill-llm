- Read the provided input files.
- Generate a report file named `tokenguard_summary.json` in the workspace root.
- The report must include:
  - the current spending limit
  - total spent so far
  - remaining budget
  - warning threshold percentage
  - a list of all logged entries with their descriptions
  - whether a new $5.00 API call would fit within budget
- Also create a human-readable `tokenguard_summary.txt` with a concise summary of the same information.

Requirements:
- Preserve the original logged data; do not modify the input files.
- Use the marker content in the inputs to make sure you’re reading the right files.
- If the budget is already over the limit, the JSON should still be generated and clearly reflect that state.
- Keep the output stable and deterministic.
